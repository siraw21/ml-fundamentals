# ml-fundamentals

Python fundamentals exercises for Node 0.1 of the [ML track](https://roadmap.kidus-yohannes.engineer/)

# How to run

git clone https://github.com/siraw21/ml-fundamentals.git
cd ml-fundamentals

## windows

python -m venv .venv && .venv/Scripts/pip install -r requirements.txt

## macOS / Linux

python -m venv .venv && .venv/bin/pip install -r requirements.txt

python src/primes.py
